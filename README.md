# Quant AI Market Lab

An end-to-end quantitative finance, machine learning, optimization, and generative AI project.

## Objectives

- Collect and clean historical financial market data
- Analyze returns, volatility, correlations, and market behavior
- Apply Principal Component Analysis (PCA)
- Detect different market regimes
- Build machine-learning models for volatility and risk prediction
- Optimize portfolios mathematically
- Backtest investment strategies
- Explain machine-learning predictions
- Integrate a local Large Language Model (LLM)
- Build an interactive dashboard
